# Assessment 1 Portfolio Working Template

**Use this as a structured evidence worksheet, not as AI-generated submission prose. Replace placeholders with your team's own verified research, client evidence and analysis.**

## Part A — Group

### Week 1 — Project Charter and Stakeholder Analysis
#### 1. Project Overview
- Project Title: Spam Detection on Emails and Social Media
- Industry Partner: [actual allocated partner/client]
- Team Members: [4 actual names + IDs]
- Project Supervisor: [actual supervisor]
- Date: [actual date]

#### 2. Project Background
Evidence/source notes:
- [client problem statement]
- [industry/research evidence]
- [why this is a cybersecurity problem]

#### 3. Project Objectives
Define three measurable objectives validated by the team/client.

#### 4. Scope
**In scope:** email text, social-media text, NLP preprocessing, ML classification, web UI, analytics, API integration point, history, testing.

**Out of scope:** image/video spam, malware execution, production mail-gateway deployment, direct moderation integration with commercial platforms unless the client explicitly adds these.

#### 5. Stakeholder Analysis
Create: Stakeholder | Role | Interest | Influence | Requirement/Need | Evidence Source

#### 6. Success Criteria
Record measurable targets approved by the supervisor/client.
